# DATABASE REQUIREMENTS

Required production database areas:

- machines
- latest heartbeat
- heartbeat history
- hardware assets
- software assets/licenses
- inventory edit audit
- software edit audit
- inventory sync matches
- notification rules
- notification state
- notification events
- client messages
- client message receipts
- deploy profiles
- branding settings
- retention settings
- users
- roles
- permissions
- ISO audit results
- history summary cache
- change events

Public GitHub repo must store schema/migrations, not private live DB files.
